# Release Smoke Checklist

- [ ] Clean checkout / dependency lock verified
- [ ] Build command and real exit code recorded
- [ ] Artifact hash and path recorded
- [ ] Critical buttons and workflows E2E tested on target runtime
- [ ] Auth, offline, timeout and permission errors tested
- [ ] Visual, responsive and accessibility evidence reviewed
- [ ] Migration and rollback path checked
- [ ] P0 acceptance gates PASS; missing tests explicitly blocked
- [ ] Owner approval recorded
