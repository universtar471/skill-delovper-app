# Delivery, release and maintenance

Deliver README, source directory/repo reference, setup prerequisites, exact install/run/build/test commands, example config, permission list, changelog, known issues and rollback steps. Only link downloadable files that actually exist.

Android: distinguish debug APK from signed production AAB/APK; include package ID, minimum OS, checksum and installation steps.
Windows: distinguish debug executable, portable ZIP and signed installer; note runtime and OS compatibility.
Web: distinguish local preview, staging and production URL; document host, secrets handling, domain and backup.

Release checklist: acceptance pass, tests captured, licenses/notices, security/privacy and data retention review, debug logging off, backup, version/tag, artifact provenance, user approval where irreversible or public. Preserve a `PROGRESS.md` recap usable by another agent.
