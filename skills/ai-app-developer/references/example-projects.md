# Sample starts for Vietnamese non-programmers

## Android video editor
Goal: locally import permitted user-owned media, cut segments, add simple text, preview and export. Start with a minimal offline editor before advanced filters, online download or social integration. Validate platform terms and copyright restrictions before supporting URL ingestion. P0: import → trim → export → verify file.

## Windows interior asset organizer
Goal: index approved local SketchUp assets and image thumbnails with tags; browse/filter and open source file. P0: select library folder → index → search → preview; permissions and large directories tested.

## Web AI image project dashboard
Goal: store project metadata, prompts and version history. P0: create project → save prompt → list versions. AI generation integration only once credentials, costs and provider APIs are authorized.

All examples are starting assumptions to refine, not implemented products.
